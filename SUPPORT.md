# Support

DirectiveGraph is an early-stage, maintainer-supported project with no guaranteed response time.

- **Usage question or suspected bug:** search issues, then use the bug template with a minimal synthetic repository tree, Python version, command, and observed output.
- **Feature proposal:** use the feature template and cite the public documentation for any new filename or precedence behavior.
- **Security issue:** follow [SECURITY.md](SECURITY.md), never a public issue.
- **Private instructions:** do not upload them. Reproduce the behavior with synthetic files.

Supported semantics are documented in [docs/SEMANTICS.md](docs/SEMANTICS.md) and [docs/API_STABILITY.md](docs/API_STABILITY.md). Natural-language conflict arbitration and organization-specific policy interpretation are outside project support.
